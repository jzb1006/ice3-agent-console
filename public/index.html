ICE3 Agent Console 是什么

ICE3 Agent Console 是一个面向汽车制造和工业数字孪生的 3D 场景在线演示。 页面主体是一座虚拟汽车制造工厂，包含车身上料、焊装机器人、喷涂、烘干、 总装、质量检测和成品物流等生产工位。用户可以在三维场景中选择设备并查看名称、 设备编号、工艺段、区域和上下游连接。

Agent 通过受控的 Scene Tool 查询设备、选择设备、聚焦设备、高亮设备和切换相机。 内置剧本可以自动完成整厂巡游和多个生产专题；场景由 ICE3 前端参数化生成， 保持设备选择身份和工位空间关系稳定。

页面能力

  • 使用鼠标旋转和缩放，使用方向键或 WASD 在场景中移动。
  • 点击设备后显示黄色高亮和右上角设备信息浮层。
  • 通过对话或快捷剧本查看焊装、涂装、总装和质量检测流程。
  • 浏览器本地剧本无需账号、API key 或服务端即可完整运行。
  • 部署时也可以配置服务端 AI 模型，并通过同一界面驱动 Scene。

技术背景

示例建立在独立 ICE3 3D Runtime 之上，当前汽车工厂由浏览器侧参数化几何生成， 使用 WebGL2、设备语义标识和可复用的 Scene Tool 协议。接入真实工厂模型时， 可以继续使用 OGC 3D Tiles 1.1、Prepared GLB、层级 LOD 和离线资产工具链； 浏览器侧不执行模型格式转换。
